# Local Made Portfolio

## Contact form setup

The contact form submits to Web3Forms from the browser. Create an access key at https://web3forms.com/ using `ryanchandupa@gmail.com`, then replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html` with that key. The form displays the thank-you message only after Web3Forms confirms the submission. Until the key is added, the page shows a setup message instead of pretending the note was sent.
